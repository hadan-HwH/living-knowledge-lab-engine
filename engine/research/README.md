# research/ — 봉인된 연구 자산 (운영 경로 밖)

> **성격:** 운영 파이프라인(ingest→prep→fold→promote→brief)은 이것들을 import하지 않는다.
> 운영 코드와 섞여 있으면 "이게 지금 돌아가는 것인가"를 매번 다시 판단해야 해서 따로 둔다.
> 테스트는 여기서도 계속 돈다 — 봉인은 "안 쓴다"이지 "썩게 둔다"가 아니다.

| 파일 | 무엇 |
|---|---|
| `cost_ladder.py`·`test_cost_ladder.py`·`pricing.yaml` | AI 비용 게이트 — 모델 사다리·캐시 단가 분할(캐시 읽기 0.1× · 쓰기 1.25×)로 $/target을 추정하고 손익분기를 판정한다 |
| `concept_divergence.py`·`test_concept_divergence.py` | 앱 간 용어 발산 검출 — 동의어(merge 제안)와 동형이의(split 경고)를 sense 일치 게이트로 가른다 |

공개본에는 비공개 코퍼스의 gold에 묶인 벤치마크 하니스·베이스라인 매니페스트·병합 실험 스크립트를
넣지 않았다.

## 여기 없는 것

`relation_canon.py`는 죽어 있었지만 **봉인하지 않고 되살렸다.** 전수조사에서 관계 어휘를
검증하는 코드가 아예 없다는 게 드러났는데, 그 게이트가 정확히 이 모듈의 일이었다.
